# AVN STORES HUB

Blossom, Play, Read — static demo storefront for plants, toys and books.

This is a demo: prices and inventory are placeholders, and no real checkout, customer login, payment processing or WhatsApp ordering is enabled.

## Cloudflare Pages
Connect this GitHub repository using Pages Git integration. Set production branch to `main`, framework preset `None`, leave build command empty, and use `/` as the output directory. Review pull-request previews before merging. Do not attach the production domain without explicit approval.

## Review
Use feature branches and pull requests. Configure GitHub rulesets to require pull requests and checks where supported.
